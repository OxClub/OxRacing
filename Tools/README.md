# Termux workflow

1. Put this repository on GitHub.
2. Add the `UNITY_LICENSE` repository secret.
3. Push to `main`.
4. GitHub Actions builds the Android APK and uploads it as an artifact.

The MVP scene is generated by the Unity Editor menu:
OxRacing → Create MVP Scene

For CI, the repository should contain `Assets/Scenes/MVP.unity`. Open the project once in Unity and run that menu item before relying on the first CI build.
